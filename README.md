# Rèm thêu trắng — wedding invitation clone

Bản dựng local dựa trên website mẫu và screen recording được cung cấp.

## Chạy local

Từ thư mục project:

```bash
python3 -m http.server 4173 --directory ren-theu-trang-clone
```

Mở `http://localhost:4173`. Có thể thêm `?open=1` để bỏ qua màn hình mở thiệp.

## Nội dung

- Màn mở thiệp và nhạc nền
- Hero satin đen, ren trắng và ảnh cưới
- Thông tin hai gia đình và ngày cưới
- Album carousel 3D
- Đếm ngược, lịch và bản đồ
- Dress code, timeline, sổ lưu bút
- Hộp quà mừng dạng modal

Toàn bộ ảnh, họa tiết và âm thanh cần thiết nằm trong `assets/` để trang có thể chạy độc lập.
